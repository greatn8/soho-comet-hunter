Original NOAA observations

Use the fixed image field, first/last buttons and timeline to judge the amount of motion. Playback compresses hours into seconds; the frame timestamp is the observation time in Sydney (AEST/AEDT). Original FITS timestamps and filenames use UTC.

Previews are 1024 × 960, reduced by two from the 2048 × 1920 FITS array. Only the array row direction is flipped; there is no solar-north rotation. The same stretch is used throughout each view. Temporal contrast can suppress slow sources and emphasize artifacts; check the original intensity view too.
